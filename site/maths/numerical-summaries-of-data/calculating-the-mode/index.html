Calculating the mode

View on Oak Academy

I can calculate the mode from data presented in a frequency table and different graphs.

Key learning points
  1. The mode can be calculated from an ungrouped frequency table.
  2. The mode can be calculated from a bar chart.
  3. The mode can be calculated from a line graph.
Keywords
Frequency
The frequency is the number of times an event occurs; or the number of individuals (people, animals etc.) with some specific property.
Mode
The mode is the most frequent value. It is a measure of central tendency representing the average of the values.
