Calculating the median

View on Oak Academy

I can calculate the median from data presented in a frequency table and different graphs.

Key learning points
  1. The median can be calculated from a line graph.
  2. The median can be calculated from an ungrouped frequency table.
  3. The median can be calculated from a bar chart.

6A large data set has 455 values. The median is the th data value when the data is in order of size.
Hint
There is an odd number of pieces of data so the median is the middle value when the data is in order of size.

Answer228
WhyTo find the position use $$ {n+1}\over {2} $$, where $$ n $$ is the number of data points.$$ {455+1}\over {2} =228 $$

WhyThe data set determines which of the measures of central tendency is the most useful to describe the data. The measure is one single value.
2An ordered data has 4751 pieces of data. The median is in the th position.
Hint
The median is in the middle of the ordered data set.
Show answer
Answer2376 / 2,376 / 2 376
WhyTo find the position use $$ {n+1}\over {2} $$, where $$ n $$ is the number of data points. $$ {4751+1}\over {2} $$ = 2376
3An estate agent records how many bedrooms each house has on their sales list. The number of houses with 2 bedrooms or fewer is . [image]
Hint
Add up the frequencies for 1 bedroom houses and 2 bedroom houses.
Show answer
Answer31 / thirty one / thirty-one
Why15 houses have 1 bedroom and 16 houses have 2 bedrooms so (15 + 16) houses have 2 bedrooms or fewer.
4A football coach records the number of goals scored in the last 45 matches. What is the median number of goals scored? [image]
Hint
Imagine writing out all the data. You need the 23rd data value that you would write down.
Show answer
Answer3
WhyIf you wrote out all the data, the median is the $${45+1}\over {2}$$th data value. The first 6 numbers are all 0, the next 7 are all 1, the next 6 are all 2. You have written 19 numbers. The next 4 numbers are all 3, so the median is 3.
5The median will __________ be in the middle bar on a bar chart.
Hint
The distribution of the data will impact the location of the median.
Show answer
Answersometimes
WhyThe median could be in any of the bars. If the vast majority of the data is the first value, then it would be in the first bar, similarly if over 50% of the data is the last value then it would be in the last bar.
6Jun records how long it takes him to get to school each day for a week. Jun's results are shown on the line graph. Jun's median journey time is minutes. [image]
Hint
There are five data points which means the median is third data value, when in order.
Show answer
Answer28
WhyA common misconception is to think the median is the data point that is middle of the horizontal axis. You need to put the journey times in order: 25, 27, 28, 29, 32 and then find the middle time.
