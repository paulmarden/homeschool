Understanding the mode

View on Oak Academy

I can understand what the mode is measuring, how it is measuring it and find the mode from data presented in a list.

Key learning points
  1. The mode is a measure of central tendency.
  2. The mode is the most frequently occurring value in a data set.
  3. There can be more than one mode.
Keywords
Mode
the most frequent value. It is a measure of central tendency representing the average of the values.
Bimodal
Sets of data which have two modes are known as bimodal data
Trimodal
Trimodal data has three modes
