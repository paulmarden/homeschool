Summarising data

View on Oak Academy

I can see that the different measures of central tendency offer a summary of a set of data.

Key learning points
  1. The mode is a useful measure of central tendency for certain data sets.
  2. The median is a useful measure of central tendency for certain data sets.
  3. The mean is a useful measure of central tendency for certain data sets.
Keywords
DataData are a collection of information.
MeanThe (arithmetic) mean for a set of numerical data is the sum of the values divided by the number of values.
MedianThe median is the central (middle) piece of data when the data are in numerical order.
ModeMode is the most frequent value. It is a measure of central tendency representing the average of the values.
Measure of central tendencyA summary that attempts to describe a whole set of data with a single value that represents the middle of the distribution.
