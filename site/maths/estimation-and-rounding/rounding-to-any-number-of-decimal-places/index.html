Rounding to any number of decimal places

View on Oak Academy

I can round numbers to any number of decimal places.

Key learning points
  1. Numbers with any number of decimal places can be represented on a number line.
  2. Any number can be rounded to a given number of decimal places.
  3. It is possible to identify the most suitable number of decimal places from the context.
  4. It can be useful to think about what the biggest and smallest values of a number rounded in context were.
Keywords
RoundTo change a number into another number that is approximately the same value but is easier to work with. E.g. round 561 to the nearest 10 is 560.
