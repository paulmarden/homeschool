Truncating

View on Oak Academy

I can estimate a value by truncating to a given degree of accuracy.

Key learning points
  1. When estimating ages, it is convention to use truncation.
  2. Truncation can be used to estimate any integer to a given accuracy.
  3. Truncation can be used to estimate any number to a given accuracy.
Keywords
Truncate
Truncation is the simplifying a number by 'cutting off' one or more of the digits and replacing them with zeros if necessary to preserve place value.
A degree of accuracy
A degree of accuracy shows how precise a number or measurement is.
