Using inequality notation for errors in calculations

View on Oak Academy

I can use inequality notation a ≤ x < b to express errors in calculations.

Key learning points
  1. You can use the values of a and b to see what the biggest and smallest answers to a calculation could have been.
  2. The range of possible answers is the error interval.
Keywords
Error interval
An error interval for a number $$x$$ shows the range of possible values of $$x$$. It is written as an inequality $$a ≤ x < b$$

1An error interval for a number $$x$$ shows the range of possible values of $$x$$. It is written as $$ a\leq x < b$$. Explain what this means.
Hint
$$$\leq$$ means less than or equal to. $$<$$ means less than.
Show answer
AnswerThe range of values include $$a$$ and not $$b$$
Why$$$ a\leq x < b$$ means you include $$a$$ and not include $$b$$.
2When a number, $$x$$, is rounded to the nearest integer the result is 63. Select the numbers which complete the error interval for $$x$$: $$\square \leq x <\square$$
Hint
Drawing a number line with 63 in the centre and, given the degree of accuracy is an integer, put 62 and 64 either side of the 63. Identify the middle of 62 and 63 and the middle of 63 and 64.
Show answer
Answer62.5 and 63.5
WhyThe smallest number when rounded to the nearest integer is 62.5, but the largest cannot be 63.5 as this rounds to 64. You show a number which is infinitely smaller than 63.5 but not equal to 63.5 using this error interval: $$62.5\leq x< 63.5$$

3A long road is made up of 3 sub roads. The 1st road measures 35 m (2 s.f), the 2nd road is 41 m (2 s.f) and the 3rd road is 48 m (2 s.f). Find the error interval for the length $$x$$ of the long road.

Answer$$$ 122.5 \leq x < 125.5 $$
WhyThe error intervals of the three roads are $$ 34.5\leq x < 35.5 $$, $$ 40.5 \leq x < 41.5 $$ and $$ 47.5\leq x < 48.5 $$. Therefore summing the lower and upper limits gives $$ 122.5 \leq x < 125.5 $$

Why$$$31\div4 \leq x <31.4\div4 $$ gives $$7.75 \leq x <7.85$$. So the length of the square is between the error interval which is 7.8 cm.
