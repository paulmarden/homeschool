Inequality notation to express error

View on Oak Academy

I can calculate possible errors expressed using inequality notation a ≤ x < b.

Key learning points
  1. When given a rounded number you can say what the biggest and smallest values of the unrounded number could have been.
  2. You can use $$a ≤ x < b$$ notation to express the range of values the unrounded number could have taken.
Keywords
Range
A range of values where every value in the range estimates to the given value.
Error interval
An error interval for a number $$x$$ shows the range of possible values of $$x$$. It is written as an inequality $$a ≤ x < b$$

1An error interval for a number $$x$$ shows the range of possible values of $$x$$. It is written as:
Hint
You want to include the number $$a$$, but not include the number $$b$$.
Show answer
Answer$$$ a\leq x < b$$
Why$$$ a\leq x < b$$ means you are including the values of $$a$$ as the smallest and not including the value of $$b$$ as the largest.
2When a number is rounded to the nearest integer the result is 8. Identify the correct range for the unrounded number.
Hint

Show answer
AnswerSmallest = $$7.5$$, Largest = $$8.4 \dot 9$$
WhyThe smallest number is 7.5 because when rounding this to the nearest integer it gives 8. The largest is $$8.4 \dot 9$$ as this rounded to the nearest integer gives 8.

4When a number, $$x$$, is rounded to the nearest integer the result is 8. Identify the error interval for $$x$$.
Hint
Draw a number line with 8 in the centre and, given the degree of accuracy is an integer, put 7 and 9 either side of the 8. Identify the middle of 7 and 8 and the middle of 8 and 9.
Show answer
Answer$$$7.5\leq x< 8.5$$
WhyThe smallest number when rounded to the nearest integer is 7.5, but the largest cannot be 8.5 as this rounds to 9. You can show a number which is infinitely smaller than 8.5 but not equal to 8.5 using this error interval: $$7.5\leq x< 8.5$$

6A distance $$x$$ km is given as 2.345 km correct to the nearest metre. Identify the error interval for $$x$$.
Hint

Answer$$$ 2.3445\leq x < 2.3455$$
WhyThe smallest number when rounded to the nearest integer is 2344.5, but the largest cannot be 2345.5 as this rounds to 2346. The error interval is $$ 2344.5\leq x < 2345.5$$. Then convert back to kilometres.
