Overestimating vs underestimating

View on Oak Academy

I can determine whether calculations using rounding or truncating will give an underestimate or overestimate.

Key learning points
  1. When multiplying or adding, using a value which has been rounded up results in an overestimate.
  2. When dividing or subtracting, using a value which has been rounded up results in an under or overestimate.
  3. Calculations using rounding or truncating will give an over or underestimate.
  4. By careful consideration of the calculation, it is possible to tell if an answer is an over or underestimate.
Keywords
Overestimate
An overestimate is an estimate for a calculation which is greater than the exact answer.
Underestimate
An underestimate is an estimate for a calculation which is less than the exact answer.
