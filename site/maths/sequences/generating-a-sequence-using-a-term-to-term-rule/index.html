Generating a sequence using a term-to-term rule

View on Oak Academy

I can appreciate that a sequence can be generated and described using term-to-term approaches.

Key learning points
  1. Sequences can be created using a rule that tells you how to find the next term from the current one.
  2. These sequences could be related additively or multiplicity.
  3. These sequences could be related in other ways.
  4. This term-to-term method is time-consuming when you want to find higher terms in the sequence.
  5. It is possible to describe the rule when given some of the terms although this may not be unique.
Keywords
Term-to-term
A term-to-term rule describes how to calculate the next term in the sequence from the previous term.

Hint
Make sure you check the rule works for all successive terms. Some different term-to-term rules can produce the same first few terms. E.g $$8\times {3\over 2} = 12, 12\times {3\over 2}=18, 18\times {3\over 2} = 27$$
Show answer
Answer8, 12, 18, 27, ... → multiply the previous term by $$3\over 2$$; 8, 12, 16, 20, ... → add 4 to the previous term; 8, 12, 20, 32, ... → add 4, then add 8, then add 12, ...; 8, 12, 20, 36, ... → double the previous term then subtract 4; 8, 12, 17, 23, ... → add 4, then add 5, then add 6, ...
WhyTerm-to-term rules are not always unique for the first 3 terms. 8, 12, 20, 32,...is 'add 4, add 8, add 12, ...' whereas 8, 12, 20, 36, ... is 'double the previous term then subtract 4'
