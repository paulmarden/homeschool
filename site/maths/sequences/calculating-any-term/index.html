Calculating any term

View on Oak Academy

I can calculate any term using the n^th term.

Key learning points
  1. The position to term rule can be expressed using n.
  2. A sequence can be generated using successive values of n .
  3. Any term can be calculated using the n^th term.
Keywords
Arithmetic sequence
An arithmetic (or linear) sequence is a sequence where the difference between successive terms is a constant.

Answerformula
WhyThe n$$^\text{th}$$ term can be used to calculate any term in a sequence so we can call it a formula for finding the n$$^\text{th}$$ term.
2If the $$n^\text{th}$$ term is $$3n+7$$ what are the first five terms?
Hint
Use substitution. $$n=1$$ will generate the first term.
Show answer
Answer10, 13, 16, 19, 22, ...
Why3(1) + 7 = 10. 3(2) + 7 = 13. 3(3) + 7 = 16. 3(4) + 7 = 19. 3(5) + 7 = 22. The first five terms of $$3n+7$$ are 10, 13, 16, 19 and 22.
3What is the 5$$^\text{th}$$ term of $$0.3n + 0.07$$?
Hint

Answer1.57
Why0.3(5) + 0.07 = 1.5 + 0.07 = 1.57 The 5$$^\text{th}$$ term of $$0.3n + 0.07$$ is 1.57.
4What are the first five terms of $$10-2n$$?
Hint

Show answer
Answer8, 6, 4, 2, 0, ...
WhyWhen $$n=1$$, $$10-2n=10-2(1)=10-2=8$$. The first term is 8.

AnswerThe 50$$^\text{th}$$ term of the sequence $$2n-1$$. → The 15$$^\text{th}$$ term of the sequence $$6n+10$$. → The 101$$^\text{st}$$ term of the sequence $${1 \over 2} n + 50$$. → The 9$$^\text{th}$$ term of the sequence $$200-11n$$.
