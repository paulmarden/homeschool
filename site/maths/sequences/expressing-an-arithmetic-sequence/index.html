Expressing an arithmetic sequence

View on Oak Academy

I can appreciate that any term in an arithmetic sequence can be expressed in terms of its position in the sequence.

Key learning points
  1. The general term of a sequence is called the n^th term.
  2. The value of n tells you what position in the sequence the term has.
  3. The term number tells you the value of n.
Keywords
n^th term
The n^th term of a sequence is the position of a term in a sequence where n stands for the term number.

4Which position-to-term rule links the pattern number to the number of squares? [image]
Hint
Consider how many squares are in each complete row. How does that relate to the pattern number?
Show answer
AnswerMultiply the pattern number by 3 then add 1.
WhyThe correct position-to-term rule is 'multiply the pattern number by 3 then add 1'. $$(1) x 3 + 1 = 4$$ squares. $$(2) x 3 + 1 = 7$$ squares. $$(3) x 3 + 1 = 10$$ squares.
5For the arithmetic sequence starting 1, 4, 7, 10, 13, ... the position-to-term rule is 'multiply by 3 and subtract 2'. What therefore, is the 100$$^\text{th}$$ term?
Hint
Take the term number 100 and apply the rule 'multiply by 3, subtract 2'
Show answer
Answer298
WhyFor the 100$$^\text{th}$$ term number we do $$(100) \times 3 -2 = 300 - 2 = 298$$
6Substitute the value $$a=6$$ into the below expressions. Order the value of the expressions from highest to lowest.
$$$17-3a$$
$$$2a-3$$
$$$3a-7$$
$$$7-a$$
Hint
For $$17-3a$$, when $$a=6$$ this becomes $$17-3a=17-3(6)=17-18$$. What value does that give us?
Show answer
Answer$$$3a-7$$ → $$$2a-3$$ → $$$7-a$$ → $$$17-3a$$
Why$$$3a-7=3(6)-7=11$$. $$2a-3=2(6)-3=9$$. $$7-a=7-(6)=1$$. $$17-3a=17-3(6)=17-18=-1$$
