Checking understanding of sequences

View on Oak Academy

I can appreciate the structure of patterns and sequences.

Key learning points
  1. Multiplication tables are an example of a sequence.
  2. Sequences might have a specific difference which can be found.
  3. Sequences can have a specific multiplier which can be found.
  4. Written methods can be used to find larger numbers in a sequence.
Keywords
Sequence
A sequence is a succession of objects, diagrams or values usually formed according to a rule.

$$$ 8\times{3\over 4}$$

$$$ 4\times{1\over 2}$$

Answer$$$4\times {2\over 5}$$ → $$$ {8\over 5}$$; $$$ 4\div{2\over 5}$$ → 10; $$$ 8\times{3\over 4}$$ → 6; $$$ 8\div{3\over 4}$$ → $$$ {32\over 3}$$; $$$ 4\times{1\over 2}$$ → 2; $$$ 4\div{1\over 2}$$ → 8

6Match the sequence with its constant multiplier.
0.2, -1, 5, ...
2, 10, 50, ...
25, 5, 1, ...
-1, 0.2, -0.04, ...

Hint

Show answer
Answer0.2, -1, 5, ... → $$$\times -5$$; 2, 10, 50, ... → $$$\times 5$$; 25, 5, 1, ... → $$$\times{1\over 5}$$; -1, 0.2, -0.04, ... → $$$\times -0.2$$; 2, 5, 12.5, ... → $$$\times {5\over 2}$$; 10, 4, 1.6, ... → $$$\times {2\over 5}$$
