Securing understanding of percentages

View on Oak Academy

I can manipulate percentages of an amount with a representation.

Key learning points
  1. Percentages of amounts can be found by combining known percentages
  2. Percentages of amounts can be represented and found using a bar model
  3. Percentages of amounts can be represented and found using double number lines
  4. Percentages of amounts can be represented and found using ratio tables
Keywords
ProportionVariables are in proportion if they have a constant multiplicative relationship.
Equivalent fractionsTwo fractions are equivalent if they have the same value.

1Proportionality means two variables have a constant __________ relationship so the variables are in proportion to each other.
Hint
Bar models, double number lines and ratio tables all display this constant relationship between numbers.
Show answer
Answermultiplicative
WhyProportionality means two variables have a constant multiplicative relationship. For example, if you walk 5 km every hour then the distance you walk is in proportion to the time you spend walking. If you walk twice as long, you will go twice as far.

AnswerProportionality
WhyProportionality means two variables have a constant multiplicative relationship. For example, if you walk 5 km every hour then the distance you walk is in proportion to the time you spend walking. If you walk twice the time, you will go twice as far.

Double number line
Ratio table
Hint
Which description matches the process of drawing a bar model, double number line or ratio table.

AnswerBar model → Good visual representation. Bars can be split in any way needed.; Double number line → Good visual representation with scaled lines.; Ratio table → Concise without visual representation and quick to construct.
WhyBar models are good visual representation and bars can be split in any way needed. Double number lines are good visual representation with scaled lines. Ratio table are concise without visual representation and quick to construct.
3What percentage of 800 is represented by the calculation: 800 ÷ 2 − 8?
Hint
Dividing by 2 is the same as finding 50%
Show answer
Answer49%
WhyDividing 800 by 2 is the same as finding 50%. 1% of 800 is 8 so subtracting 8 is the same as subtracting 1%. 50% − 1% = 49%, so 49% has been found.
