Increase by a percentage

View on Oak Academy

I can calculate percentage changes (increase).

Key learning points
  1. A bar model can be used to find a percentage increase.
  2. A double number line can be used to find a percentage increase.
  3. A ratio table can be used to find a percentage increase.
Keywords
Proportionality
If two things are proportional then the ratio of part to whole is maintained and the multiplicative relationship between parts is also maintained.
