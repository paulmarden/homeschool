Perpendicular to a given line through a given point

View on Oak Academy

I can use the properties of a rhombus to construct a perpendicular to a given line through a given point.

Key learning points
  1. A rhombus can be constructed from two congruent isosceles triangles.
  2. This can be used to construct a perpendicular to a line through a point.
  3. This perpendicular has special properties that can be investigated.
  4. Shortest distances can be found using constructions with perpendicular lines.
Keywords
Bisect
To bisect means to cut or divide an object into two equal parts.
Rhombus
A rhombus is a parallelogram where all sides are the same length.
