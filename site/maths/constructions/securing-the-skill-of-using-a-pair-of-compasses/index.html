Securing the skill of using a pair of compasses

View on Oak Academy

I can use a pair of compasses to draw different circles.

Key learning points
  1. A pair of compasses can be used to draw a circle with a particular radius.
  2. A pair of compasses can be used to draw two circles that intersect.
  3. A pair of compasses can be used to draw two circles that only intersect once.
Keywords
Radius
The radius is any line segment that joins the centre of a circle to its edge.
Compass
A pair of compasses is a tool which can be used to draw circles and arcs. A pair of compasses is sometimes referred to just as a compass.
