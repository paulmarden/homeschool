Constructing scatter graphs by utilising technology

View on Oak Academy

I can construct scatter graphs from data presented in a number of different ways using technology.

Key learning points
  1. Scatter graphs can be constructed quickly using spreadsheets.
  2. Scatter graphs can be constructed quickly using Desmos.
  3. Changing which axis is used for which variable affects how the scatter graph appears.
Keywords
Scatter graphA visual representation for bivariate data. It can be useful when determining the nature of the relationship between the two variables

1Which two options below are examples of spreadsheet software?

Select all that apply.

Hint
Spreadsheets are large tables with lots of cells, which can be inputted with data. We can use spreadsheet to perform calculations, analyse data and plot graphs.

AnswerGoogle Sheets; Microsoft Excel
WhyGoogle Sheets and Microsoft Excel are spreadsheet software which can be used to analyse data and plot graphs.
2Which type of graph is a visual representation for bivariate data?
Hint
Bivariate data contains two variables. Which graph can be used to display one variable on one axis and the other variable on the other axis?
Show answer
Answerscatter graph
WhyA scatter graph contains two axes, with each axis representing one of the variables in a set of bivariate data.
3Which is another term to describe the response variable in bivariate data?
Hint
The response variable is affected by the other measure in bivariate data.
Show answer
Answerdependent variable
WhyThe response variable can also be called the dependent variable because its value is affected by the other measure in bivariate data.
4Which two terms describe a measure in bivariate data whose value is predicted to affect the other measure?

Select all that apply.

Hint
This variable is not affect by the other variable. Also, changes in this variable are predicted to cause changes in the other variable.
Show answer
Answerexplanatory variable; independent variable
WhyChanges in the explanatory/independent variable are predicted to cause changes in the other variable.
5Which variable should be represented on the horizontal axis of a scatter graph?
Hint
A scatter graph usually shows how changes to the variable on the horizontal axis affects the variable on the vertical axis.
Show answer
Answerindependent variable
WhyThe horizontal axis usually shows how changes to the independent variable affects the value of the dependent variable. It doesn't imply any changes are due to the independent variable though.
6A set of bivariate data measures hours of daylight in a day and maximum temperature for each day. Which variable is most likely to be the independent variable?
Hint
The independent variable is the one that is likely to be the cause of changes to the other variable.
Show answer
Answerhours of daylight
WhyThe hours of daylight in a day is independent of the temperature. It is likely that the maximum temperature is affected by the hours of daylight during the day. In fact both are affected by the time of year but the hours of light more predictably so.
