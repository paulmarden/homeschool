Solution to an equation

View on Oak Academy

I can appreciate that a solution is a value that makes the two sides of an equation balance.

Key learning points
  1. In an expression the variable can take any value.
  2. In a linear equation there is a particular value that makes the equation balance.
  3. The value is the solution to the linear equation.
  4. When graphing a linear expression this value represents a single point.
Keywords
Solution
A solution to an equality with one variable is a value which, when substituted, maintains the equality between the expressions.
