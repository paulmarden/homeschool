Solving complex linear equations

View on Oak Academy

I can solve complex linear equations, including those involving reciprocals.

Key learning points
  1. Any linear equation written in the form Ax + B = C can be solved.
  2. Equations involving division by a constant can be manipulated to reach the form Ax + B = C.
  3. Equations involving division by a variable can be manipulated to reach the form Ax + B = C.
Keywords
Equation
An equation is used to show two expressions that are equal to each other.
