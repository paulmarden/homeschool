Checking understanding of algebraic notation

View on Oak Academy

I can represent situations using algebra.

Key learning points
  1. Missing numbers can be found in context.
  2. Missing number problems can be expressed algebraically.
  3. Pairs of numbers that satisfy an equation with two unknowns can be found.
  4. Real life situations can be expressed using algebra.
Keywords
Integer
An integer is any positive or negative whole number or zero
Expression
An expression contains one or more terms, where each term is separated by an operator.
Equation
An equation is used to show 2 expressions that are equal to each other.

Hint

Answer$$${1\over 2} \times 8 $$; $$$8\over 2$$

3Match up equivalent terms.
$$$-{x\over 4}$$
$$$4x\over- 5$$
$$$-5x\over 4$$
$$$-x\over -4$$
$$$-10x\over -8x$$
Hint
A negative value divided by a negative value gives a positive value.

Answer$$$-{x\over 4}$$ → $$$-{1\over 4} x$$; $$$4x\over- 5$$ → $$$-{4\over 5} x$$; $$$-5x\over 4$$ → $$$-{5\over 4} x$$; $$$-x\over -4$$ → $$${1\over 4} x$$; $$$-10x\over -8x$$ → $$$\frac{5}{4}$$

4Match each expressions to its description.
$$$3b - 7$$
$$$3(b - 7)$$
$$$b - 7 \times 3$$
$$$7 - 3b$$
$$$3(7 - b)$$
Hint
Subtraction is not commutative so make sure your terms are written the correct way round.
Show answer
Answer$$$3b - 7$$ → a number multiplied by 3 then subtract 7; $$$3(b - 7)$$ → a number subtract 7 then multiplied by 3; $$$b - 7 \times 3$$ → a number subtract the product of 7 and 3; $$$7 - 3b$$ → a number multiplied by 3 then subtracted from 7; $$$3(7 - b)$$ → a number subtracted from 7 then multiplied by 3

6Andeep has 2 blocks, one block is 5 cm smaller than the other. The blocks have a combined height of 121 cm. How tall is the larger block? cm
Hint
Draw a diagram to help, one block on top of the other will be 121 cm tall.
Show answer
Answer63 / 63 cm / 63cm
WhyOne block is 5 cm taller than the other. $$121 - 5 = 116$$, so two of the smaller block are 116 cm tall. $$116\div 2 = 58$$. The smaller block is 58 cm, so the larger block is $$58 + 5 = 63$$, which is 63 cm.
