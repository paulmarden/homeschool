Unit 4 of 10

Solving linear equations

View on Oak Academy

In this unit pupils will learn how to find a value that satisfies a linear relationship when one value is known both with a single step operation, and multiple step operations. A variety of cases are explored including using brackets and rearranging.

Algebra

Why this, why now

Further to graphing linear sequences in the previous unit, pupils now learn to connect understanding with solving linear equations after demonstrating how for each point on a linear graph there is a unique solution to the equation of the line.

Prior knowledge
Understand and apply inverse operations
Simplify algebraic expressions
Solve one-step and two-step equations

01Checking understanding of algebraic notation
I can represent situations using algebra.02Securing understanding of equality
I can appreciate how to maintain equality between two statements.03Different types of equations
I can recognise that there are many different types of equations of which linear is one type.04Equality in an equation
I can appreciate that in an equation the two sides of the equals sign balance.05Solution to an equation
I can appreciate that a solution is a value that makes the two sides of an equation balance.06Many equations, one solution
I can understand that a family of linear equations can all have the same solution.07Solving simple linear equations with an additive step
I can solve a linear equation requiring a single additive step.08Solving simple linear equations with a multiplicative step
I can solve a linear equation requiring a single multiplicative step.09Preparing to solve two step linear equations
I can understand that an equation needs to be in a format to be ready to be solved, through collecting like terms on each side of the equation.10Solving two step linear equations
I can see that when an additive step and a multiplicative step are required to solve an equation, the order of operations will not affect the solution.11Rearranging to solve linear equations
I can recognise that equations with unknowns on both sides of the equation can be manipulated so that the unknowns are on one side and then solve this equation.12Solving complex linear equations
I can solve complex linear equations, including those involving reciprocals.13Brackets in equations
I can appreciate the significance of the bracket in an equation.14Solving linear equations where brackets are used
I can recognise that there is more than one way to remove a bracket when solving an equation.15Solving complex linear equations involving brackets
I can solve equations involving brackets where simplification is necessary first.16Solving linear equations graphically using technology
I can explore how to solve linear equations graphically via dynamic software.17Problem solving with linear equations
I can use my knowledge of solving linear equations to solve problems.
