Preparing to solve two step linear equations

View on Oak Academy

I can understand that an equation needs to be in a format to be ready to be solved, through collecting like terms on each side of the equation.

Key learning points
  1. An equation with both a multiplicative and additive step can be solved using a bar model.
  2. The solution can be formalised using algebra.
  3. Any linear equation written in the form Ax + B = C can be solved.
  4. Any linear equation can be written in the form Ax + B = C by collecting like terms.
Keywords
