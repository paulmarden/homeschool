Brackets in equations

View on Oak Academy

I can appreciate the significance of the bracket in an equation.

Key learning points
  1. Multiplying both sides of an equation by the same term can be shown using brackets.
  2. An expression involving brackets can be expanded.
  3. Equations involving brackets can be expressed in words.
  4. Equations involving brackets can be represented using bar models.
Keywords
Equation
An equation is used to show two expressions that are equal to each other.
