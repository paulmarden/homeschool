Solving simple linear equations with a multiplicative step

View on Oak Academy

I can solve a linear equation requiring a single multiplicative step.

Key learning points
  1. An equation involving an multiplicative step can be represented with a bar model.
  2. Using the bar model you can write all the arrangements of the equation with an multiplicative step.
  3. One of the arrangements will give the solution to the equation.
  4. This can be written algebraically to find the solution.
Keywords
ReciprocalThe reciprocal is the multiplicative inverse of any non-zero number.
