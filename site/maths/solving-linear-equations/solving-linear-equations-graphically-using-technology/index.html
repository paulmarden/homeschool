Solving linear equations graphically using technology

View on Oak Academy

I can explore how to solve linear equations graphically via dynamic software.

Key learning points
  1. A linear expression expressed on a graph represents a straight line.
  2. This line can be used to find one variable when given the other.
  3. A horizontal or vertical line represents a particular value of a variable.
  4. Where this meets the linear graph the solution of a linear equation.
Keywords
Equation
An equation is used to show two expressions that are equal to each other.
Solution
The solution to an equality is the value which, when substituted, maintains the equality between expressions.
