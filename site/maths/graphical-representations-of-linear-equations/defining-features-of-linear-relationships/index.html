Defining features of linear relationships

View on Oak Academy

I can appreciate that there are two key elements to any linear relationship: rate of change and intercept point.

Key learning points
  1. There is always a common difference in an arithmetic sequence.
  2. There is always a constant rate of change on a linear graph.
  3. There is always an initial value in an arithmetic sequence.
  4. There is always an intercept point with the y-axis on a linear graph.
  5. These two features uniquely describe any linear relationship.
Keywords
Rate of change
The rate of change is how quickly one variable changes with respect to another. If constant, there is a linear relationship.
Intercept
An intercept is the coordinate where a line or curve meets a given axis.
