Adding a resource

Drop files in assets/resources/ and register them, or point at a URL:

python tools/add_resource.py --lesson UNIT/LESSON \
    --title "Title" --url assets/resources/thing.pdf --kind worksheet

python tools/add_resource.py --unit UNIT --title "…" --url "https://…"
python tools/add_resource.py --general --title "…" --url "https://…"

python build.py

Or edit data/resources.json directly — it is the source of truth and lives in git, so resources are shared across every machine that clones the repo.
