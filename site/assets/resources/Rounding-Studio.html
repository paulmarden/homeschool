Handler notes (for Dad)

  • Order matters. Missions follow Oak's sequence exactly; each Oak lesson is the "spec" and the mission is the job. Watch or read the Oak lesson first, then do the mission — the drill assumes the lesson's method.
  • Shipping a mission = evidence boxes ticked + a confidence rating. The Oak exit quiz is the formal check; a score under 4/6 means do the drill to a streak of 8 and retry the quiz next day, not the same day.
  • The drills auto-mark and accept numerically equal answers (2.5 for 2.50), but the model answer always shows the correct number of places — worth a glance when it differs.
  • Studio builds need Roblox Studio on a PC/Mac. Paste the code into a Script in ServerScriptService, press Play, and read the Output window (View → Output). Nothing needs publishing.
  • Field missions use the real Roblox website or app. Screenshots go in the case file as evidence.
  • Progress syncs to this page for anyone signed in to the same Claude workspace; otherwise it's saved in the browser. The green dot in the top bar shows which.
